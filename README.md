# YouTube / 哔哩哔哩 文案批量下载（Chrome 插件）

在 **YouTube 频道/播放列表页** 或 **B站 UP主投稿页**，一键扫描整页视频，批量抓取
字幕/转录文案，每个视频导出一个 Markdown，最后打包成一个 `.zip` 下载。

- **YouTube** `.md`：标题、链接、作者、发布时间、观看数、评论数、视频描述、字幕文案。
- **哔哩哔哩** `.md`：标题、链接、UP主、发布时间、播放、弹幕、评论、点赞、视频简介、字幕文案。

（评论数等为尽力抓取，少数视频可能显示「不可用」。）

- 自动抓取该视频可用的字幕（人工或自动生成，不挑语言——取 YouTube 转写面板默认显示的那种）。
- 支持普通视频和 **Shorts 短视频**。
- 默认导出纯文本（去时间戳），可勾选保留时间戳。
- 抓不到字幕的视频会汇总进 `_未抓取列表.md`。
- 打包用浏览器原生 `CompressionStream`，**零第三方依赖**。

## 安装（加载未打包扩展）

1. Chrome 地址栏输入 `chrome://extensions`
2. 打开右上角「**开发者模式**」
3. 点「**加载已解压的扩展程序**」，选择本文件夹 `yt-transcript-grabber`
4. 工具栏出现红色下载图标即成功

## 使用

1. 打开列表页：
   - YouTube：频道视频页 `https://www.youtube.com/@频道名/videos` 或播放列表 `/playlist`
   - B站：UP主投稿页 `https://space.bilibili.com/UID/video`
2. 点插件 → 「**扫描本页视频**」（YouTube 自动滚动；B站 自动翻页）
3. 勾选要抓的视频，按需调整「保留时间戳 / 压缩包名」
4. 点「**下载选中文案 (zip)**」

> 抓取在后台进行：插件会**新开一个后台标签页**逐个打开视频、等转写面板加载、扒取，
> 然后自动关闭它。关掉弹窗也不会中断；重新点开插件能看到进度。
> **每个视频约需 10–20 秒**（个别慢的更久），所以视频多时整体会跑几分钟到十几分钟。

## 工作原理（为什么是这套笨办法）

2026 年实测，YouTube 对字幕接口的反爬已经很重：

- `timedtext` 字幕直链 → 返回**空内容**（需要 poToken）。
- 内部 `get_transcript` 接口 → `400 FAILED_PRECONDITION`（同样被风控挡）。

所以本插件**不碰这些接口**，而是骑在 YouTube 自己的渲染管线上——它内部会处理 poToken：

1. **扫描**：在频道/列表页注入脚本，自动滚动收集所有 `watch?v=` 与 `/shorts/` 链接和标题。
2. **抓字幕**：后台标签页真实导航到每个视频页，然后：
   - **静音播放视频**（关键！实测有些视频的转写只有在播放时才加载，暂停会一直转圈）；
   - 滚动触发懒加载，等「显示转写文稿」按钮出现并点开；
   - 等转写面板把字幕段渲染进 DOM（兼容 `transcript-segment-view-model` 与
     `ytd-transcript-segment-renderer` 两种结构），按时间戳+文本去重后取文本。
   - 元信息（标题/作者/时间/观看数/描述/评论数）从页面的 `ytInitialPlayerResponse`
     / `ytInitialData` 直接读。
3. **打包**：在页面内用 `CompressionStream('deflate-raw')` 生成标准 zip 并下载。

后台 service worker（`background.js`）负责调度与逐个导航。

### 哔哩哔哩（完全不同，纯接口、快得多）

B站不需要播放、不需要扒 DOM 面板——它的字幕走自家接口：

1. **扫描**：在 UP主投稿页逐页点「下一页」累积所有视频（标题取非封面链接，避开播放量/时长）。
2. **抓字幕**（已实测）：用一个后台 B站 标签页发接口（带你的登录态）：
   - `x/web-interface/view?bvid=` → 标题/UP主/发布时间/播放/弹幕/评论/点赞/简介；
   - `x/player/wbi/v2`（**wbi 签名**）→ 字幕轨列表（优先 AI 中文 `ai-zh`），拿到字幕 JSON 地址。
     ⚠️ 必须用 wbi 签名版：非签名的 `player/v2` 对部分视频会把字幕地址返回空（曾导致「字幕地址为空」）。
     签名用 `lib/bili-wbi.js`（md5 已对标准向量校验）。
   - 字幕本体在 `aisubtitle.hdslb.com`，网页跨域被 CORS 挡，所以由**后台**（带 host 权限）抓回 → `body[].content` 拼成文案。
3. 纯接口、可并行（默认同时 5 个），比 YouTube 快很多。
4. **AI 字幕通常需要登录** B站；没生成 AI 字幕 / UP主未开启字幕的视频抓不到，列入 `_未抓取列表.md`。

## 开发 / 测试

纯逻辑（zip 字节结构、去重、文本/元信息格式化）有一套不依赖框架的测试：

```bash
node test/run-tests.mjs
```

用真实 `unzip -t` 校验 CRC/结构、`ditto` 解压比对内容（需 Node 18+）。
DOM 抓取部分依赖真实 YouTube 页面，无法离线单测，已在真实浏览器逐步验证过机制。

## 文件结构

```
manifest.json          扩展清单（MV3）
popup.html/.css/.js    弹窗界面与控制逻辑
background.js          后台引擎：逐视频导航 + grabInPage(打开转写面板/播放/抓取)
lib/page-helpers.js    注入页面：扫描视频列表 / 打包下载
lib/format.js          纯格式化（去重/文本拼接/Markdown），后台与测试共用
icons/                 图标
test/run-tests.mjs     单元测试
```

## 已知限制

- **慢**：每个视频要真实加载页面+等转写渲染，约 10–20 秒/个，无法很快。
- **会员视频**：用你当前登录账号抓——你**已订阅**该频道会员的视频可抓；**未订阅**的会被
  拦截，列入 `_未抓取列表.md`。
- 有的视频 YouTube 自己也加载不出转写（面板一直转圈/显示「无法显示字幕」），超时后列入未抓取。
- **字幕语言**取决于你 YouTube 账号的字幕语言偏好（转写面板默认显示哪种就抓哪种）。若想统一某语言，
  可在 YouTube 设置里调整字幕语言偏好。
- 评论数取自页面评论预览计数，部分视频可能「不可用」。
- YouTube 页面结构若大改，`background.js` 里 `grabInPage` 的选择器可能要更新。
